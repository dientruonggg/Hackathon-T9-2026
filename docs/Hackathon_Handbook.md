# AI Tinkerers - Da Nang: Agents, Everywhere (Hackathon Handbook)

## The Challenge
Build an agent for a place people already work, talk, or live, then make it meaningfully more useful because of that context.
That could mean the web, mobile, Slack, Teams, messaging, browsers, workplace software, voice, wearables, robotics, or an entirely new environment.

## Build Something Real
The goal is a working prototype that can be demonstrated by the end of the day. Keep the scope tight, prioritize the core interaction, and make sure the agent’s environment is essential to the experience.
You may use any technical stack. 

## Build Eligibility
Every submitted project must be a net-new build created during the official hackathon period.
Teams may use existing templates, reusable components, libraries, prompts, starter code, or other building blocks. However, the project being submitted and its core functionality must be built during the event.

## Your Submission
Every team must submit:
- A project title
- A written description
- A public GitHub repository
- A two-minute demonstration video
- A social media post about the project tagging the event partners

**Deadline:** Complete submission in this portal by 4:00 p.m. on Saturday 12 September.

## Judging in Da Nang
Criteria (Scored 1 to 5 each):
1. Core Requirements & Functionality
2. Innovation & Theme Alignment
3. Technical Execution & Integration
4. Usefulness & Agentic Experience

## Your 2-minute video
Show the agent working in its real environment, end to end. Say who it is for and why it belongs there rather than in a chat window. Show the integration, not slides. Keep it small (720p, under 100 MB). Upload to YouTube (unlisted) or Loom.
